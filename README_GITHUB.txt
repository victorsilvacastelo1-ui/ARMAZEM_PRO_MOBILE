ARMAZÉM PRO - GERAR APK PELO GITHUB ACTIONS

PASSO A PASSO:

1. Crie um repositório novo no GitHub.
2. Envie TODO o conteúdo desta pasta para a raiz do repositório.
   IMPORTANTE: o arquivo settings.gradle deve ficar logo na raiz.

3. No GitHub, abra a aba Actions.

4. Clique no workflow:
   "Gerar APK Armazem Pro"

5. Clique:
   Run workflow > Run workflow

6. Aguarde a execução ficar verde.

7. Abra a execução concluída.

8. Em Artifacts, baixe:
   ARMAZEM_PRO_APK

9. Extraia o arquivo baixado.
   Dentro estará:
   app-debug.apk

10. Envie o APK ao celular e instale.

O APK abre:
https://armazempro.com.br/sistema/

Assim usa o mesmo sistema online e o mesmo Supabase do PC.

OBS:
Este pacote gera APK de teste (debug), ideal para você instalar e testar agora.
Depois podemos preparar a versão assinada para publicação.
