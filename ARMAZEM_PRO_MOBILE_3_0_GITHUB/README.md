# Armazém Pro Mobile 3.0

Aplicativo Android otimizado para celular e conectado ao mesmo sistema online usado no computador.

## O que esta versão faz

- Mantém login, assinatura e permissões do Armazém Pro oficial.
- Usa o mesmo banco online, portanto celular e PC enxergam o mesmo estoque.
- Barra Android para Dashboard, Produtos, Entradas e Saídas.
- Menu rápido para Inventário, Kits, Armazéns, Devolução e Equipe.
- Interface responsiva para celular.
- GitHub Actions gera o APK automaticamente.

## Gerar APK no GitHub

1. Envie ESTE CONTEÚDO para a raiz do repositório, mantendo as pastas `app` e `.github`.
2. Abra a aba **Actions**.
3. Abra **Gerar APK Armazem Pro**.
4. Clique **Run workflow** se necessário.
5. Quando ficar verde, abra a execução e baixe **ARMAZEM-PRO-MOBILE-APK** em Artifacts.

O APK gerado será `app-debug.apk` dentro do ZIP do Artifact.
