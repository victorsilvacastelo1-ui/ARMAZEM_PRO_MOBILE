ARMAZÉM PRO APP ANDROID — VERSÃO ATUALIZADA PARA CELULARES ATUAIS

Compatibilidade:
- compileSdk 36
- targetSdk 36 (Android 16)
- minSdk 24 (Android 7.0 ou superior)
- AndroidX
- WebView moderno
- Layout redimensionável para celulares, tablets e dobráveis
- JDK 17 recomendado
- Preparado para o requisito de target API 36 do Google Play em 2026

Funcionamento:
O aplicativo abre https://armazempro.com.br/sistema/
e utiliza o mesmo Armazém Pro online / Supabase do computador.

TESTAR:
1. Extraia o ZIP.
2. Abra a pasta no Android Studio atualizado.
3. Use JDK 17.
4. Instale Android SDK Platform 36 no SDK Manager.
5. Aguarde a sincronização do Gradle.
6. Execute em um celular Android ou emulador.

GERAR APK:
Build > Build App Bundles or APKs > Build APKs.

Observação:
O projeto mantém minSdk 24 para não limitar apenas a aparelhos novos.
O alvo é Android 16/API 36, adequado à geração atual e às exigências recentes do Google Play.
